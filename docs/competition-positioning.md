# Competition Positioning

## Category

StillHere is **business continuity infrastructure for the long tail of the web**.

Its thesis is simple:

> An agent-ready version of stale information is still stale information.

WebMCP can make a page easier for an agent to operate. StillHere addresses the earlier trust problem: what happens when the page is no longer a reliable source of current business truth?

## Product sequence

```text
Recover → Reconcile → Approve → Publish → Transact
```

StillHere recovers fragmented evidence, exposes disagreements, lets an agent stage explanations and resolutions, reserves authority for the human, publishes only accepted facts, and binds later discovery and inquiry tools to that same Passport version.

## Challenge differentiation

| Common agent-enablement approach | StillHere |
| --- | --- |
| Expose an existing interface to an agent | First establish which claims are publishable |
| Treat retrieved page text as operating context | Keep source text untrusted and separate from tool definitions |
| Give the agent broad actions | Use six route-scoped tools with narrow authority |
| Hide preparation and action state | Show proposals, decisions, draft values, approval, and errors in the human UI |
| Update a mutable profile | Publish a versioned accepted-facts snapshot |
| Treat a destination as supported or unsupported | Preserve `AVAILABLE_BY_INQUIRY` as a distinct qualification |

The centerpiece is not a chatbot or a generic MCP generator. It is the visible transformation from conflicting evidence to a human-controlled Business Passport.

## Demonstration moments

The three-minute story has five high-signal moments:

1. A bounded assessment separates website condition from business condition.
2. Four sources visibly disagree about phone, MOQ, Japan availability, and certification.
3. The agent stages proposals but the Passport preview remains unchanged until human decisions occur.
4. The human excludes an unsupported certification claim and publishes Passport v2.
5. Search and inquiry tools consume the same published snapshot; editing the draft revokes approval and removes submission capability.

## What StillHere is not

The challenge build is not:

- a business directory, website builder, or modernization service;
- an unrestricted crawler or third-party form automation system;
- identity, legal-status, KYC, registry, or certification verification;
- an ecommerce checkout, order, payment, or delivery system;
- a durable multi-tenant backend.

Those exclusions keep the build focused on the novel human-agent reconciliation boundary.

## Evidence-bounded claims

The Rwenzori Harvest company, recovered records, representative decisions, and inquiry receipts are fictional. The arbitrary-site assessor observes one bounded public HTML response and never turns that observation into representative or legal claims.

The production demo proves a collaboration and authority pattern. It does not claim that browser-local storage or a process-local receipt Map is a production system of record.
